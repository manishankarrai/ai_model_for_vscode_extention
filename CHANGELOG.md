# Change Log

All notable changes to the "MM3" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.1] - 2026-09-13

### Added

- Initial release of the MM3 AI Agent extension.
- Local-first project indexing, context selection, and read-only investigation.
- Ask and Agent interaction modes with streaming responses and citations.
- Approval-gated code changes with diff review and rollback support.
- Project memory, agent selection, billing, wallet, and dynamic agent catalog support.

### Changed

- Removed production diagnostic console and output-channel logging.
